# Scrum - [LNbits](https://lnbits.com) extension

Project management with paid tasks. Create scrum boards where completing tasks earns sats, adding a financial incentive to your team workflows.

## How it works

Set up a scrum board with tasks and assign sat rewards to each. Team members claim tasks and receive payment upon completion and approval.

## Features

- Kanban-style task boards
- Sat rewards per task
- Task assignment and tracking
- Payment on completion

## Usage

1. Enable the extension in LNbits
2. Create a new scrum board
3. Add tasks with sat rewards
4. Team members claim and complete tasks
5. Approve completions to release payments
